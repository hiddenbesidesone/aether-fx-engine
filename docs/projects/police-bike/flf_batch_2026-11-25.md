## What we learned

- **Fast mode ignores the negative prompt** (the 4-step LoRAs run at cfg 1), so "beacon lights off" or "no feet" can't be
  enforced there. Fixes, cheapest first:
  1. **Another seed** in fast mode (~6 min). Fixed spoon and glock. It reduced the beacon to a one-frame flicker, but the baton kept its feet.
  2. **Quality mode + a negative** naming the problem (~28 min): `feet, shoes, legs, floor, glow, halo, outline` for the first-person
     clips, `flashing lights, glowing blue beacon, police lights on` for the bike. Spoon and glock came out clean.
- First-person walks: Wan "sees" a walking camera and adds the walker's feet. Expect it on some seeds. It's at the bottom
  edge, away from the arm, so a garbage matte also works.
- **Beacon:** Wan associates police bikes with lit beacons. Even unlit in the start frame, it switches them on. If the film
  wants them off, use the quality-mode negative, or patch the beacon in compositing (it's small and static).
- The visor in `visor-down-idle` is down but clear, so the face shows through. That's what the start frame has.
- Logos: the BMW roundels and the crest are still in (they're in the start frames). Run `plate_prep.py fix` on these, or
  send cleaned stills next time.
